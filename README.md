# E-commerce App for GitHub Actions Practice

## GitHub Actions Fundamentals

### 1. What is CI/CD
- Continuous Integration (CI) ensures code changes are automatically tested and merged.
- Continuous Deployment/Delivery (CD) automates the release process to production.

### 2. Workflows, Jobs, Steps, Actions
- **Workflows**: Automated processes defined in YAML files.
- **Jobs**: A set of steps executed on a runner.
- **Steps**: Individual tasks within a job.
- **Actions**: Reusable units of code that perform tasks.

### 3. Creating Workflows
- Define workflow in `.github/workflows/` directory.
- Trigger workflows
